## Dotfiles Included
- **Neovim**: Code\Text Editor.
- **Tmux**: Session and Window manager in Terminal.
- **Kitty**: Primary Terminal Emulator.
- **Alacritty**: Terminal emulator.
- **Cava**: Audio visualizer.
- **Yazi**: Terminal file manager
- **ZSH**: Shell
